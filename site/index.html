Featureseverything listed exists today

  • SSH terminal

    xterm.js terminal with host-key verification; password, key, keyboard-interactive or SSH-agent login.

  • Integrated SFTP

    Browse, upload, download, rename and delete beside the terminal, with drag and drop and context menus.

  • Your own editor

    Edit remote files in the editor you use. Every upload is confirmed first, and approval is not remembered across reconnects.

  • Independent sessions

    Any number of tabs, even to one server; each has its own connection and state.

  • Split view

    Up to six panes. Drag a tab onto a pane edge; moving it keeps the session.

  • Local terminals

    PowerShell, PowerShell 7, cmd, WSL, bash, zsh and fish, plus your own shell profiles.

  • Saved connections

    Folders, search and recent sessions. Passwords stay in the operating system's keychain.

  • Themes and palettes

    Four themes, ten terminal palettes, custom colors and per-tab palettes.

  • Keyboard shortcuts

    Customizable, and kept clear of terminal programs such as vim and tmux.

  • Private by design

    No telemetry, no accounts. Logs never contain secrets or terminal content, and a guided action removes all saved passwords.

  • Readable

    Any installed monospace font, interface scale 70–150%, optional status bar.

  • Application lock

    An optional password lock for the whole application.

Themesscreenshots only

Dark is the default: neutral near-black panels with a soft peach accent.

Industrial Olive and Source Gray are original designs inspired by early-2000s game-engine interfaces; no third-party artwork. Terminal palettes: PeachTerm Dark and Light, Industrial Olive Console, Source Gray Console, Classic Dark, Green Phosphor, Amber Phosphor, One Dark, Nord, Solarized Dark.
